# 基础设施选型与预算：腾讯云自购服务器

> 更新日期：2026-07-15  
> 适用场景：Ops Desk Kimi Code v1，无 GPU，纯 API Key 调用模型  
> 数据库说明：PostgreSQL 部署在购买的腾讯云服务器上（非本地个人电脑）

---

## 1. 服务器选型结论

### 1.1 推荐：腾讯云轻量应用服务器 Lighthouse

**理由**：
- 价格便宜，配置透明，流量包模式适合聊天类低并发。
- 控制台集成防火墙、快照、监控，一人运维省时间。
- 不需要 CVM 的复杂网络规划。

### 1.2 具体配置建议

| 配置 | CPU | 内存 | 带宽 | 流量包 | 系统盘 | 月费参考 |
|---|---|---|---|---|---|---|
| **乞丐版（最低可跑）** | 2核 | 2GB | 4Mbps | 300GB/月 | 50GB SSD | ~¥50–70 |
| **推荐版（稳妥）** | 2核 | 4GB | 5Mbps | 500GB/月 | 60GB SSD | ~¥80–110 |
| **舒适版** | 4核 | 8GB | 8Mbps | 800GB/月 | 80GB SSD | ~¥150–200 |

**v1 推荐：2核4G5M（¥80–110/月）**。

原因：
- FastAPI + PostgreSQL + Nginx 同时运行，2G 内存较紧张。
- 4G 内存可支撑几十个并发 + PG 缓冲。
- 5Mbps 带宽足够 SSE 流式 + 页面访问。

-  Lighthouse 新用户特惠（轻量服务器首单）**：https://cloud.tencent.com/act/pro/lighthouse
- 腾讯云 CVM 首页（备用扩展）：https://cloud.tencent.com/product/cvm

## 2. 域名与备案

### 2.1 域名注册

- 推荐 `.com` 或 `.cn`。
- 腾讯云域名注册：https://cloud.tencent.com/product/domains
- `.com` 首年约 ¥60–80，`.cn` 首年约 ¥30–50。

### 2.2 必须完成的备案

| 备案 | 费用 | 耗时 | 说明 |
|---|---|---|---|
| 域名实名认证 | 免费 | 1–3 工作日 | 购买域名后必须完成 |
| ICP 备案 | 免费 | 10–20 工作日 | 通过腾讯云备案助手提交 |
| 公安备案 | 免费 | 1–3 工作日 | ICP 通过后 30 天内 |

腾讯云 ICP 备案入口：https://cloud.tencent.com/product/ba

### 2.3 个人备案限制

- 网站名称不能含“平台”“系统”“服务”等商业词。
- 若产品有用户注册/UGC，建议用**个体工商户/公司主体**备案。
- v1 不开放注册，仅有邀请密钥登录，可用个人备案，但网站名称需合规。

## 3. SSL 证书

- 腾讯云免费 DV SSL（TrustAsia）：https://cloud.tencent.com/product/ssl
- 或使用 Let's Encrypt + acme.sh 自动续期。
- 建议 SSL 终止在 Nginx，后端 FastAPI 跑 HTTP（127.0.0.1:8000）。

## 4. 对象存储与备份

### 4.1 腾讯云 COS

- 产品页：https://cloud.tencent.com/product/cos
- 用途：数据库备份、日志归档、前端构建物历史版本。

### 4.2 备份策略

| 备份项 | 频率 | 方式 | 月费参考 |
|---|---|---|---|
| PostgreSQL 逻辑备份 | 每日 | `pg_dump` + 上传到 COS | 存储 ¥0.15/GB + 流量 |
| 服务器快照 | 每周 | 腾讯云 Lighthouse 快照 | ~¥0.15/GB |
| 应用日志 | 每日 | `logrotate` + 可选 COS | 少量 |

## 5. 网络与安全

### 5.1 安全组/防火墙

仅开放：
- 22（SSH，建议改非默认端口）
- 80（HTTP，备案后）
- 443（HTTPS，备案后）

### 5.2 安全基线

- SSH 密钥登录，禁用密码。
- 安装 `fail2ban`。
- PostgreSQL 不暴露公网，仅 `127.0.0.1` 或 Docker 内部访问。
- API Key 仅存环境变量，不写入代码/Git。
- 启用腾讯云 Cloud Monitor 基础告警（CPU/内存/磁盘）。

## 8. 省钱技巧

- 新用户首单 Lighthouse 通常 ¥50–80/年，可先买一年测试。
- 域名选 `.cn` 更便宜，但 `.com` 更通用。
- SSL 用免费证书，不要买付费证书（个人项目没必要）。
- 备份用 `pg_dump` + COS 低频存储，不要买数据库托管服务。
- 监控用腾讯云免费 Cloud Monitor，不要买付费版。
