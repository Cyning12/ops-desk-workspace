## 设计裁定：这一波交付的是诚实，不是代码

勘察（survey §6）确认五个文章术语在原型 0 命中：Watchdog、fast/slow path、speculative、
inline&spill+chained recall、BYOM。全部实现是研究级工作量，且多数与原型已有机制方向相左
（如 speculative 需要可逆效果队列，而原型的队列为了持久化恰恰不可逆）。

裁定：写**对齐总账**而非实现。理由正是原型自己的第一原则——「对外只承诺真实状态」；
这条原则用到文章本身：对外材料引用文章概念时，必须能查到它在原型里的真实形态。

## docs/010 的三判定结构

- **Landed, under different names**：Router/Worker（→main/executor session）、异步 ReAct loop
  （→ticket stage 机）、IM≤100 词、存算分离（→Engine 纯领域+Effects 队列）、两级过滤
  （→gate/assessment，且实际有 Source 预过滤第三层）。安全引用，但引用原型形态而非文章词。
- **Partial**：Watchdog（hourly check 是操作者约定而非组件；错的 watchdog 比没有更糟）；
  BYOM（只有按角色路由，无任意 provider 注册表）。
- **Direction only**：speculative execution（与不可逆持久队列设计相左，留研究方向）；
  inline&spill+chained recall（read-pointer 分页已覆盖运营需求，链式召回是其上的协议构想）。

每条附采纳成本，但账本明确：这些记录不构成 build 承诺。
