# 配图提示词（统一风格 · 99 公版 3 张 + 11 篇插画 1 张）

> 用法：每张图 = 【单图描述】+【统一风格基线】拼接后整段投喂（即梦 / Midjourney / 通义万相均可）。
> 若用 Midjourney，末尾追加 `--ar 16:9 --style raw --no text, letters, watermark`。

## 统一风格基线（每张必带）

```
极简扁平矢量插画，浅灰白色背景，柔和漫射光，单一强调色青蓝（teal），大面积留白，
构图清爽克制，线条干净，无文字、无字母、无数字、无水印、无 logo、无界面截图元素
```

## 图 1 · 系统全貌（99 篇 §3 用，对应 00 索引的 ASCII 架构图）

```
一座"分拣中枢"的正面平视隐喻图：左侧三枚小信封与对话气泡（代表消息触发）排队流入
中央一座双层指挥台（orchestrator，台面上有微小的仪表盘与指示灯）；指挥台向右分出
三条并排流水线，每条一种小图标——放大镜（评估）、卡片工单板（工单）、小机器人
俯身写字（执行）；流水线末端汇入一条横向的档案卷轴带（留痕/账本），卷轴上整齐
排列着小书签。人物不出现，尺度小巧，像一套干净的桌面机械装置。
```

## 图 2 · 三决策裁决 review（99 篇，07 案例段）

```
一张浅色评审桌面俯视 45°：桌面中央摊开一份长文档（像 PR 评审页，但纯图形无字），
文档上有三行并列的选项框，每行各被一支不同深浅的青蓝色标记笔打上勾；文档右侧
空白处有一只手的剪影正在写批注线；桌面角落放着一杯咖啡与两枚回形针。整体传达
"在评审中逐条裁决、落笔留痕"。
```

## 图 3 · 委托授权与闸表代录（99 篇，08 案例段）

```
两个人物的半身协作场景（扁平风、无面部细节）：左侧人物（维护者，着深色上衣）
将一枚小印章递向右侧的小机器人助手；机器人手持羽毛笔，正在一张竖立的四格
checklist 闸表上勾选，每一格旁边浮着一个微小引号气泡（象征"引用签认依据"）；
闸表顶部有一条细线连接回维护者手中的印章（象征"授权在先"）。背景空净。
```

## 图 4 · 智能体演进插画（11 篇用）

```
从左到右的横向时间带，三个时代节点由一条细线串联：①一台老式打字机；
②一台复古终端机（ CRT 屏幕泛微光）；③一个机器人半身坐在栅栏式闸门之后写代码，
闸门上方挂着四块小标牌（纯图形无字），机器人头顶一枚对话气泡；三个节点的
背景色从左至右由灰蓝渐亮到暖白，象征从"人操作机器"到"模型出判断、harness 出边界"。
```
